# Data Layers

Data layers use WebGL shaders to generate tiles on the fly from Digital Elevation Map (DEM) tilesets.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| Layer Name | string | Unique display name |
| URL | string | Path to DEM tileset (from `rasterstotiles1bto4b.py`) |
| Legend | string | Path to `legend.csv` |
| Initial Visibility | bool | On by default |
| Min/Max Zoom | integer | Zoom level range |
| Bounding Box | string | `minLon,minLat,maxLon,maxLat` |
| Time Enabled | bool | Enable temporal data |

## Shader Raw Variables

Data layers require a `shader` raw variable. Supported shader types:

### Colorize Shader

Dynamic color ramps based on viewport min/max data values:

```json
{
  "shader": {
    "type": "colorize",
    "units": "m",
    "noDataValues": [0],
    "sigfigs": 3,
    "ramps": [["#FF0000", "transparent", "#0000FF"]]
  },
  "downloadURL": "url_to_data/data.tif"
}
```

- `units`: Suffix for displayed values
- `noDataValues`: Values treated as no-data (max 3 values)
- `sigfigs`: Significant figures for displayed values
- `ramps`: Array of color ramp arrays (hex colors; `"transparent"` is supported)
- `downloadURL`: Optional link to source data download

### Image Shader

Default — renders raw data as-is. Useful for testing and development.

See `docs/pages/Configure/Layers/Data/Data.md` for the full specification.
