# Configure Page Tabs Reference

Detailed reference for each tab in the Configure page (`/configure`).

## Initial Tab

Sets the initial state on page load:

| Setting | Type | Description |
|---------|------|-------------|
| Mission Name/Folder | string | Rename mission (disabled by default) |
| Initial Site | string | Override view with a site code |
| Initial Latitude | float | Starting latitude (decimal degrees) |
| Initial Longitude | float | Starting longitude (decimal degrees) |
| Initial Zoom | integer | Starting [zoom level](https://wiki.openstreetmap.org/wiki/Zoom_levels) |
| Planet Radius Major | float | Meters from planet center to equator |
| Planet Radius Minor | float | Meters from planet center to pole |
| Zoom Level of Map Scale | integer | Default zoom for functions (also adds scale bar button) |

## Overall Tab

Global mission settings including mission metadata, coordinate frames, and general options.

## Projection Tab

Configure the map projection for the mission's planetary body. Supports standard EPSG projections and custom projections via Proj4 strings. See also `docs/pages/Configure/Projections/planetcantile.md` for planetary tile matrix sets.

## Look Tab

Visual appearance customization including color theme, logo placement, and UI element visibility.

## Panels Tab

Configure panel layouts:
- Panel logo images and URLs
- Header/footer content
- Custom panel configurations

Example panel config:
```json
{
  "url": "http://example.com/logo.png",
  "title": "Mission Logo"
}
```

## Time Tab

Configure temporal controls:
- Enable/disable time controls
- Set time range bounds
- Configure time format display
- Set default time step intervals

## Tools Tab

Enable/disable tools per mission and configure tool-specific variables. Each tool can have custom configuration passed through its `config.json` variables schema.

## Coordinates Tab

Configure coordinate display formats and available coordinate frames (lat/lon, easting/northing, site-relative, etc.).

## Layers Tab

The primary interface for managing map layers. See `03-layer-types.md` for layer type details.

Operations:
- Add new layers
- Configure layer properties
- Reorder layers (drag and drop)
- Group layers into hierarchies
- Import/export layer configurations

See `docs/pages/Configure/Tabs/` for detailed documentation on each tab.
