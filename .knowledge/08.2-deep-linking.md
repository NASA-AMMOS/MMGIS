# Deep Linking

MMGIS supports deep linking to share specific map states via URL parameters.

## URL Parameters

Deep links encode the full map state including:
- Map center and zoom level
- Active layers and their visibility
- Selected tools and their state
- Time control settings
- 3D globe camera position

## Short Links

MMGIS includes a URL shortener that converts long deep links into concise shareable URLs:
- Short links follow the pattern: `{domain}/?s={code}` (e.g., `mmgis.example.com/?s=mdxeg`)
- Created via `POST /api/shortener/shorten`
- Expanded via `POST /api/shortener/expand`
- Can be disabled with `DISABLE_LINK_SHORTENER=true`

## Special URL Parameters

- `?forcelanding=true` — Force the landing page to display (even with only one mission)
- `?mission=MissionName` — Go directly to a specific mission

## JavaScript API

The `mmgisAPI` provides programmatic deep linking support:
- `mmgisAPI.getUrlString()` — Get current state as URL parameters
- Tools can implement `getUrlString()` to persist their state in deep links
