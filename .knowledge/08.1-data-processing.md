# Data Processing

MMGIS includes utilities for processing geospatial data into formats suitable for web mapping.

## Raster Tiling

The primary tiling script is `auxiliary/gdal2customtiles/gdal2customtiles.py`. It converts raster data into hierarchical tile sets (TMS format) for use as tile layers.

### Usage

```bash
python auxiliary/gdal2customtiles/gdal2customtiles.py [options] input_file output_dir
```

This generates `{z}/{x}/{y}.png` tile pyramids with an optional `tilemapresource.xml` metadata file.

## DEM Processing

For 3D globe terrain, DEMs must be converted to RGBA-encoded tile sets using `auxiliary/1bto4b/rasterstotiles1bto4b.py`. This encodes elevation values into the RGBA channels of PNG tiles.

## Cloud Optimized GeoTIFFs (COGs)

MMGIS supports COGs served through TiTiler. COGs enable efficient remote access to large raster datasets without downloading the entire file.

## STAC Integration

When STAC is enabled (`WITH_STAC=true`), MMGIS can:
- Browse and search STAC catalogs
- Display STAC items as map layers
- Use `stac-collection:` URL prefix for layer configuration

See `docs/pages/DataProcessing/` for detailed processing guides.
