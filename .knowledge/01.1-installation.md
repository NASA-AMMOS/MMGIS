# Installation

## Installing with Docker

1. Clone the repo: `git clone https://github.com/NASA-AMMOS/MMGIS`
2. From root: `npm install`

### Building

```bash
docker build -t mmgis .
```

Or use a prebuilt image from [GitHub Packages](https://github.com/NASA-AMMOS/MMGIS/pkgs/container/mmgis).

### Preparing

#### .env

- Copy `sample.env` to `.env`: `cp sample.env .env`
- Update `DB_NAME`, `DB_USER`, `DB_PASS`
- If using the postgis/postgres image from docker-compose, set `DB_HOST` to the service name (e.g., `db`)

#### docker-compose.yml

- Copy `docker-compose.sample.yml` to `docker-compose.yml`
- Set `POSTGRES_PASSWORD` in the `db` service and use it for `DB_PASS`
- Create a host `Missions` directory and map it to `/usr/src/app/Missions`
- Optional STAC and TiTiler services can be removed if unneeded

### Running

```bash
docker-compose up -d
```

### First Time UI Setup

1. Navigate to `http://localhost:8888/configure`
2. Sign up for an Administrator account (first user is auto-admin)
3. Click **NEW MISSION**, enter a name, click **MAKE MISSION**
4. Navigate to `http://localhost:8888`

## Installing Without Docker

### System Requirements

1. [Node.js v22.20.0+](https://nodejs.org/en/download/)
2. [PostgreSQL v16+](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads) with [PostGIS 3+](https://postgis.net/install/)
3. Create a new PostgreSQL database

### Python Environment (for GDAL/adjacent services)

Install [micromamba 2+](https://mamba.readthedocs.io/en/latest/installation/micromamba-installation.html):

```bash
micromamba env create -y --name mmgis --file=python-environment.yml
micromamba activate mmgis
```

### Steps

```bash
cp sample.env .env
# Edit .env with your database credentials

npm install

# Build the configure sub-app
cd configure && npm install && npm run build && cd ..

# Initialize database and start server
npm start
```

## Port Map

| Port | Service | Notes |
|------|---------|-------|
| 8888 | Express API server, `/configure` admin UI, static assets | Always running |
| 8889 | Webpack dev server (main React app) | Development mode only — browse the app here |

In development mode, `PORT+1` (8889) is used by webpack-dev-server. The Express API on port 8888 handles all API requests, and the dev server proxies to it automatically.
