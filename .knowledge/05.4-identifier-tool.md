# Identifier Tool

Query raw pixel values from remote raster data sources.

## Features

- Click on the map to sample pixel values from raster layers
- Supports multi-band raster queries
- Works with both local tiles and remote COG/TiTiler sources
- Uses `POST /api/utils/getbands` endpoint for value retrieval

## Use Case

Scientists can inspect exact data values at specific locations — useful for elevation queries, spectral analysis, and data validation.

See `docs/pages/Tools/Identifier/Identifier.md` for the full documentation.
