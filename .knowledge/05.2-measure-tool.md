# Measure Tool

Distance measurement and elevation profiling tool.

## Features

- **Distance Measurement**: Click-to-measure paths on the map
- **Elevation Profiles**: Generate elevation cross-sections along paths (requires DEM tile layers)
- **Coordinate Readout**: Display coordinates at measurement points
- **Multi-segment paths**: Measure cumulative distances along complex routes

## Requirements

- Elevation profiles require a tile layer with a DEM Tile URL configured
- Works in both 2D map and 3D globe views

See `docs/pages/Tools/Measure/Measure.md` for the full documentation.
