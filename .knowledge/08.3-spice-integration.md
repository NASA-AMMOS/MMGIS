# SPICE Integration

SPICE (Spacecraft Planet Instrument C-matrix Events) is a NASA ancillary information system for computing geometric information for robotic spacecraft missions.

MMGIS uses SPICE through [spiceypy](https://github.com/AndrewAnnex/SpiceyPy) (Python).

## Tools Requiring SPICE

- **ShadeTool**: Computes sun illumination angles for shadow simulation

## Configuration

### Enable Kernel Downloads

1. Set `SPICE_SCHEDULED_KERNEL_DOWNLOAD=true`
2. Copy `/Missions/spice-kernels-conf.example.json` to `/Missions/spice-kernels-conf.json`
3. Configure kernels for your mission bodies and targets

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `SPICE_SCHEDULED_KERNEL_DOWNLOAD` | Enable periodic kernel downloads | `false` |
| `SPICE_SCHEDULED_KERNEL_DOWNLOAD_ON_START` | Also trigger on startup | `false` |
| `SPICE_SCHEDULED_KERNEL_CRON_EXPR` | Download schedule (cron) | `"0 0 */2 * *"` |

### Kernel Configuration Schema

```json
{
  "body": {
    "{NAIF_BODY_NAME_OR_ID}": {
      "description": "Kernels for this body",
      "kernels": [
        "URL to kernel",
        {
          "url": "URL to meta-kernel (.tm)",
          "mkRoot": "Root path for $KERNELS prefix",
          "mkRegex": "Regex to filter meta-kernel entries"
        }
      ],
      "targets": {
        "{NAIF_TARGET_NAME_OR_ID}": {
          "description": "Additional kernels for this target",
          "kernels": ["URL to kernel"]
        }
      }
    }
  }
}
```

Kernels are downloaded to `/spice/kernels/`. Body and target names must be valid NAIF SPICE identifiers.

See `docs/pages/Configure/SPICE/SPICE.md` and [NAIF SPICE](https://naif.jpl.nasa.gov/naif/) for more details.
