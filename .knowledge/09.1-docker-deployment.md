# Docker Deployment Guide

## Quick Start

```bash
# 1. Prepare environment
cp sample.env .env
cp docker-compose.sample.yml docker-compose.yml
# Edit both files with your database credentials

# 2. Build and run
docker build -t mmgis .
docker-compose up -d

# 3. First-time setup
# Navigate to http://localhost:8888/configure
# Create admin account (first user is auto-admin)
```

## docker-compose.yml Configuration

### Required Settings

1. Set `POSTGRES_PASSWORD` in the `db` service
2. Set `DB_PASS` in MMGIS service to match
3. Set `DB_HOST` to the database service name (e.g., `db`)

### Volume Mounts

Map host directories to container paths:
```yaml
volumes:
  - ./Missions:/usr/src/app/Missions    # Mission data persistence
  - ./ssl:/usr/src/app/ssl              # SSL certificates (if HTTPS)
```

### Optional Services

Remove any unwanted services from `docker-compose.yml`:
- `stac` — Set `WITH_STAC=false` in `.env`
- `titiler` — Set `WITH_TITILER=false` in `.env`
- `titiler-pgstac` — Set `WITH_TITILER_PGSTAC=false` in `.env`
- `veloserver` — Set `WITH_VELOSERVER=false` in `.env`

## Operations

```bash
# View logs
docker-compose logs -f mmgis

# Restart a service
docker-compose restart mmgis

# Stop all services
docker-compose down

# Rebuild after code changes
docker build -t mmgis . && docker-compose up -d mmgis
```

## Production Checklist

1. Set `NODE_ENV=production`
2. Set a strong `SECRET` (min 24 chars, use `openssl rand -hex 64`)
3. Configure `TITILER_ALLOWED_URL_PATTERNS` for SSRF protection
4. Set appropriate `AUTH` mode (`local` or `csso`)
5. Ensure `Missions/` directory is mounted as a persistent volume
6. Consider setting `HIDE_CONFIG=true` after initial setup if not needed
7. Configure `FRAME_ANCESTORS` if embedding MMGIS in iframes
