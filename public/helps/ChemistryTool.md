## Tool: Chemistry

_Visualize chemical composition data for map features._

### Overview

The Chemistry Tool displays compositional chemistry data (such as oxide percentages or elemental abundances) for selected map features. Data is presented as interactive bar charts and plots.

### Interface

- **Place Name** — Shows the name of the currently selected feature.
- **Single/Multi** — Toggle between viewing a single feature's chemistry or comparing multiple features.
- **Chart** — Interactive bar chart showing chemical composition values.

Click on a map feature with chemistry data to display its composition in the tool panel.

### Configuration

| Variable | Description |
|---|---|
| `chems` | Array of chemical element/compound names to display |
| `chemLayerVar` | Layer variable containing the chemistry data |
