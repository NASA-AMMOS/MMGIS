## Tool: Animation

_Create animated GIF and MP4 exports of map views over time._

### Overview

The Animation Tool guides users through a step-by-step workflow to create map animations by capturing frames across a time range and exporting them as GIF or MP4 files.

### Interface

#### Steps

1. **Select Area** — Choose a bounding box for the animation frame.
2. **Set Time Range** — Define the start time, end time, and frame interval.
3. **Configure Playback** — Set frame rate, resolution, and playback options.
4. **Export** — Generate and download the animation as GIF or MP4.

### Configuration

| Variable | Description |
|---|---|
| `exportFormats` | Available export formats (gif, mp4) |
| `maxFrames` | Maximum number of frames allowed |
