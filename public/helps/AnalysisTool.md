## Tool: Analysis

_Temporal analysis and comparison of geospatial data layers._

### Overview

The Analysis Tool provides time-range selection and comparison capabilities for analyzing changes in geospatial data over time. It supports querying and visualizing data within defined temporal windows.

### Interface

#### Time Range

- **Start/End Time** — Define the temporal window for data analysis.
- **Compare Two Time Ranges** — Toggle dual time-range mode for before/after comparisons.

#### Analysis Options

- **Layer Selection** — Choose which data layers to include in the analysis.
- **Statistics** — View computed statistics for the selected data within the time range.

### Configuration

| Variable | Description |
|---|---|
| `defaultTimeRange` | Initial time range for analysis |
| `layers` | Layers available for temporal analysis |
