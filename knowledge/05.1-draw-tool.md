# Draw Tool

The Draw Tool is MMGIS's most complex tool, providing collaborative vector editing with versioned history.

## Core Features

- **Multi-user collaboration**: Real-time sync via WebSockets
- **Versioned history**: Complete undo/redo with action tracking
- **Feature templates**: JSON schema validation for feature metadata
- **Lead/review/publish workflow**: Quality control for critical data
- **Intents**: Semantic categorization (ROI, Campaign, Trail, etc.)
- **File operations**: Create, edit, delete, merge, split, clip

## File Structure

- **Files** (`user_files`): Containers for features with metadata, permissions, and templates
- **Histories** (`file_histories`): Snapshots of file state at each action
- **Features** (`user_features`): Individual geometries with PostGIS encoding

## File Visibility

- **Private**: Only owner can see
- **Public (read-only)**: All users can see, only owner can edit
- **Public (list-editors)**: Specific users can edit
- **Public (all-editors)**: Any user can edit

## Feature Descriptions and Tags

File descriptions encode organizational tags:
- `~^{tag}`: Elevated/prioritized folder
- `~@{tag}`: Regular folder
- `~#{tag}`: Feature tag

## History Actions

| Index | Action |
|-------|--------|
| 0 | Add |
| 1 | Edit |
| 2 | Delete |
| 3 | Undo |
| 5 | Clip (add over) |
| 6 | Merge |
| 7 | Clip (add under) |
| 8 | Split |

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/draw/add` | Add feature |
| POST | `/api/draw/edit` | Edit feature |
| POST | `/api/draw/remove` | Remove feature |
| POST | `/api/draw/undo` | Undo last action |
| POST | `/api/draw/merge` | Merge features |
| POST | `/api/draw/split` | Split feature |
| POST | `/api/files/make` | Create file |
| POST | `/api/files/getfiles` | List files |
| POST | `/api/files/publish` | Publish file |

## Publishing Workflow

Lead users can:
1. Collect features from various layers into a Lead file
2. Run validation checks (no duplicate names/UUIDs, containment rules)
3. Publish the file — stores validated features in `publisheds` table

See `docs/pages/Tools/Draw/Draw.md` for the full documentation.
