# Image Layers

GeoTIFF or Cloud Optimized GeoTIFF (COG) layers. Currently supports single-banded images.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| Layer Name | string | Unique display name |
| URL | string | Path to GeoTIFF or COG |
| Legend | string | Path to `legend.csv` |
| Fill min/max | bool | Fill with min/max color outside data range |
| Hide No Data Value | bool | Hide pixels with nodata value |
| Transform COG | bool | Enable on-the-fly rescaling and coloring |
| Min Pixel Value | float | Minimum value for rescaling |
| Max Pixel Value | float | Maximum value for rescaling |
| Units | string | Value suffix (e.g., `m` for meters) |
| Colormap | string | Color ramp from TiTiler/js-colormaps |
| Initial Visibility | bool | On by default |
| Initial Opacity | float | 0 to 1 |
| Min/Max Zoom | integer | Zoom level range |
| Bounding Box | string | `minLon,minLat,maxLon,maxLat` |

## COG Support

When TiTiler is enabled (`WITH_TITILER=true`), COGs can be dynamically tiled and styled without pre-processing. The Transform COG option enables on-the-fly rescaling and colorization.

See `docs/pages/Configure/Layers/Image/Image.md` for the full specification.
