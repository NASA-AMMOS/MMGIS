# Query Layers

User-queryable layers with data from external search endpoints. Currently supports ElasticSearch.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| Layer Name | string | Unique display name |
| Endpoint | string | Search endpoint URL |
| Type | enum | Endpoint type |
| Stroke/Fill Color | CSS color/prop | Feature styling |
| Stroke Weight | integer | Border thickness |
| Fill Opacity | float | Fill transparency |
| Radius | integer | Point marker radius |

## Raw Variables

```json
{
  "useKeyAsName": "propKey",
  "query": {
    "fields": { "field1": 100, "field2": 0 },
    "geoshapeProp": "geometry_field",
    "must": [{ "match": { "fieldName": "value" } }],
    "sort": [{ "fieldName": { "order": "desc" } }],
    "size": 1000
  },
  "links": [{ "name": "Detail", "link": "https://example.com/{id}" }]
}
```

Key query options:
- `bodyWrapper`: Wrap request body in a string template
- `withCredentials`: Send cookies with requests
- `esResponses`: Look for data in `responses.0.data.hits.hits`
- `geoshapeProp`: Property name for spatial searches
- `must`: Required query conditions
- `collapse`: Deduplicate by field
- `sort`: Result ordering
- `size`: Maximum results

See `docs/pages/Configure/Layers/Query/Query.md` for the full specification.
