# JavaScript API

MMGIS exposes a client-side JavaScript API (`mmgisAPI`) for programmatic interaction with the map and tools.

## Accessing the API

The `mmgisAPI` object is available globally after MMGIS initializes.

## Capabilities

### Map Control
- Navigate to coordinates
- Set zoom level
- Control map projections

### Layer Management
- Toggle layer visibility
- Set layer opacity
- Access layer data

### Tool Activation
- Programmatically open/close tools
- Configure tool state

### Event Handling
- Subscribe to map events
- Listen for layer changes
- React to tool state changes

### Deep Linking
- Get current state as URL parameters
- Restore state from URL parameters
- Create shareable links

### Authentication
- `mmgisAPI.initialLogin()` — Trigger login flow
- Useful when `SKIP_CLIENT_INITIAL_LOGIN=true`
