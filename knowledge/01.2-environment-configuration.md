# Environment Configuration

Environment variables are set in `MMGIS/.env`. A sample file `MMGIS/sample.env` is provided. On startup, erroneous setups are logged.

> **Important**: When updating or adding environment variables, you must update all three locations: `.env`, `sample.env`, and `docs/pages/Setup/ENVs/ENVs.md`.

## Required Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `SERVER` | Server type: `node` or `apache` (deprecated) | `''` |
| `AUTH` | Authentication mode: `off`, `none`, `local`, `csso` | `''` |
| `NODE_ENV` | `production` or `development` | `production` |
| `SECRET` | Cryptographically random string for session cookie signing (min 24 chars). Generate with `openssl rand -hex 64`. **Required — server will not start without it.** | None |
| `DB_HOST` | PostgreSQL host | `null` |
| `DB_PORT` | PostgreSQL port | `null` |
| `DB_NAME` | Database name | `null` |
| `DB_USER` | Database user | `null` |
| `DB_PASS` | Database password | `null` |

### AUTH Modes

- **`off`**: No authentication. Users cannot sign up or log in. Tools requiring login will not work.
- **`none`**: No authentication. Users can still sign up and log in from within MMGIS.
- **`local`**: Credentials required. Admin must create accounts or set `AUTH_LOCAL_ALLOW_SIGNUP=true`.
- **`csso`**: Cloud Single Sign On service proxied in front of MMGIS.

## Optional Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `PORT` | Server port | `8888` |
| `HTTPS` | Use HTTPS server (requires `HTTPS_KEY` and `HTTPS_CERT`) | `false` |
| `HTTPS_KEY` | Relative path to SSL key | — |
| `HTTPS_CERT` | Relative path to SSL cert | — |
| `DB_POOL_MAX` | Max DB pool connections (CPUs × 4 recommended) | `10` |
| `DB_POOL_TIMEOUT` | DB connection timeout (ms) | `30000` |
| `DB_POOL_IDLE` | DB idle connection timeout (ms) | `10000` |
| `DB_SSL` | Connect to DB via SSL | `false` |
| `DB_USER_TEST` | Test-specific database user (required for tests) | `null` |
| `DB_PASS_TEST` | Test-specific database password (required for tests) | `null` |
| `AUTH_LOCAL_ALLOW_SIGNUP` | Allow guest signup when `AUTH=local` | `false` |
| `VERBOSE_LOGGING` | Extra logging for development | `false` |
| `ROOT_PATH` | Deploy under a subpath (e.g., `/path/to/mmgis`) | `""` |
| `MAIN_MISSION` | Skip landing page, go straight to this mission | `''` |
| `FORCE_CONFIG_PATH` | Path to a JSON config file as the only mission | `''` |
| `HIDE_CONFIG` | Make configure page inaccessible | `false` |
| `LEADS` | List of usernames treated as leads (elevated permissions) | `[]` |
| `ENABLE_MMGIS_WEBSOCKETS` | Enable backend websockets for layer updates | `false` |
| `ENABLE_CONFIG_WEBSOCKETS` | Notify configure users of config changes | `false` |
| `GENERATE_SOURCEMAP` | Build JavaScript source maps | `false` |
| `FRAME_ANCESTORS` | CSP frame-ancestors header for embedding | `null` |
| `FRAME_SRC` | CSP frame-src header for external iframes | `null` |
| `DISABLE_LINK_SHORTENER` | Disable short link creation | `false` |
| `CLEARANCE_NUMBER` | Website clearance number | `CL##-####` |

## SPICE Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `SPICE_SCHEDULED_KERNEL_DOWNLOAD` | Enable periodic kernel downloads | `false` |
| `SPICE_SCHEDULED_KERNEL_DOWNLOAD_ON_START` | Also trigger download on start | `false` |
| `SPICE_SCHEDULED_KERNEL_CRON_EXPR` | Cron expression for downloads | `"0 0 */2 * *"` |

## Adjacent Server Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `WITH_STAC` | Enable STAC catalog service | `false` |
| `STAC_PORT` | STAC proxy port | `8881` |
| `WITH_TIPG` | Enable TiPG vector service | `false` |
| `TIPG_PORT` | TiPG proxy port | `8882` |
| `WITH_TITILER` | Enable TiTiler service | `false` |
| `TITILER_PORT` | TiTiler proxy port | `8883` |
| `TITILER_ALLOWED_URL_PATTERNS` | SSRF protection URL patterns (JSON array of regex) | `[]` |
| `WITH_TITILER_PGSTAC` | Enable TiTiler-PgSTAC mosaicking | `false` |
| `TITILER_PGSTAC_PORT` | TiTiler-PgSTAC proxy port | `8884` |
| `WITH_VELOSERVER` | Enable Veloserver | `false` |
| `VELOSERVER_PORT` | Veloserver proxy port | `8104` |

### Custom Adjacent Servers

```bash
ADJACENT_SERVER_CUSTOM_0=["true", "route_name", "service_name", "port"]
```

See `docs/pages/Setup/ENVs/ENVs.md` for the full reference.
