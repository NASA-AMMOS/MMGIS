# Shade Tool

Sun/shadow illumination simulation based on SPICE ephemeris data.

## Features

- Compute sun illumination angles for any time and location
- Visualize shadow patterns on terrain
- Useful for mission planning and hazard assessment

## Requirements

- SPICE kernels must be configured (see `08.3-spice-integration.md`)
- `SPICE_SCHEDULED_KERNEL_DOWNLOAD=true` for automatic kernel updates
- DEM data for terrain shadow casting

See `docs/pages/Tools/Shade/Shade.md` for the full documentation.
