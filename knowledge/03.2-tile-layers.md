# Tile Layers

Hierarchical raster imagery served as web map tiles.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| Layer Name | string | Unique display name |
| URL | string | Tile URL with `{z}/{x}/{y}.png` placeholders |
| DEM Tile URL | string | Optional elevation data URL for 3D globe |
| Legend | string | Path to `legend.csv` |
| Tile Format | enum | `TMS`, `WMTS`, or `WMS` |
| Initial Visibility | bool | On by default |
| Initial Opacity | float | 0 to 1 |
| Minimum Zoom | integer | Lowest zoom level |
| Maximum Native Zoom | integer | Highest native zoom level |
| Maximum Zoom | integer | Highest display zoom (scales tiles beyond native) |
| Bounding Box | string | `minLon,minLat,maxLon,maxLat` |
| Time Enabled | bool | Enable temporal tiles |
| Time Type | enum | `Global` or `Individual` |
| Time Format | string | URL time format (default: `%Y-%m-%dT%H:%M:%SZ`) |
| Composited Time Tile | bool | Composite multiple time steps |
| Refresh Interval | bool/number | Auto-refresh every N seconds |

## Tile Formats

- **TMS**: Standard 256×256 tiles organized by `{z}/{x}/{y}`. URL: `path/{z}/{x}/{y}.png`
- **WMTS**: Same as TMS but with inverted Y-axis
- **WMS**: Generic web map service. Append `?layers=<layer_name>` to URL. Use `&TILESIZE=` to change tile size.

## Auto-populate from XML

The Configure page can automatically populate Minimum Zoom, Maximum Native Zoom, and Bounding Box from a `tilemapresource.xml` file found in the tileset directory.

## DEM Tiles

For 3D globe terrain, provide a DEM tile URL pointing to RGBA-encoded elevation tiles generated by `auxiliary/1bto4b/rasterstotiles1bto4b.py`.

See `docs/pages/Configure/Layers/Tile/Tile.md` for the full specification.
