# Vector Layers

GeoJSON or KML feature layers. When the URL ends with `.kml`, MMGIS automatically converts to GeoJSON.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| Layer Name | string | Unique display name (no special characters) |
| Kind of Layer | enum | Special interaction behavior (see Kinds) |
| URL | string | Path to GeoJSON/KML or `geodatasets:name` |
| Controlled | bool | Whether layer can be dynamically updated |
| Legend | string | Path to `legend.csv` |
| Initial Visibility | bool | On by default |
| Visibility Cutoff | integer | Hide below this zoom level (negative inverts) |
| Initial Opacity | float | 0 (transparent) to 1 (opaque) |
| Time Enabled | bool | Enable temporal filtering |
| Time Type | enum | `Requery` (re-fetch) or `Local` (filter in-place) |
| Start Time Property | string | Property path for range start (dot notation) |
| Main Time Property | string | Primary time property path |
| Time Format | string | URL time format (default: `YYYY-MM-DDTHH:mm:ssZ`) |
| Refresh Interval | bool/number | Auto-refresh every N seconds |
| Stroke Color | CSS color/prop | Border/line color |
| Fill Color | CSS color/prop | Fill color |
| Stroke Weight | integer | Border thickness (pixels) |
| Fill Opacity | float | Fill transparency |
| Radius | integer | Point marker radius |

## URL Formats

- **File path**: `Layers/data.geojson` (relative to mission directory)
- **Geodataset**: `geodatasets:my_dataset_name`
- **Time-enabled**: `path/{starttime}/{endtime}/data.geojson`

## Data-Driven Styling

Use `prop:property_name` for color fields to derive colors from feature properties:
- If the property value is a valid CSS color, it's used directly
- If it's a non-color string, a consistent hash-based color is assigned

## Dynamic Extent

For large datasets, enable Dynamic Extent to load features based on current viewport bounds. Features are re-fetched as the user pans/zooms.

See `docs/pages/Configure/Layers/Vector/Vector.md` for the full specification.
