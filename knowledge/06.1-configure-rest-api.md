# Configure REST API

The Configure REST API provides programmatic access to mission configuration management. All endpoints are under `/api/configure/*` and are restricted to Site Admins.

## Authentication

- Requires admin session (permission "111" or "110")
- Even when `AUTH=off`, admin endpoints require proper session
- Long-term tokens can be used for automated access (created via Configure page)

## Whitelisted Endpoints (Public Access)

These endpoints are accessible without admin authentication:
- `GET /api/configure/get` — Get mission configuration
- `GET /api/configure/missions` — List available missions
- `GET /api/geodatasets/get` — Get geodataset
- `GET /api/geodatasets/search` — Search geodatasets

## Admin Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/configure/add` | Create new mission |
| POST | `/api/configure/save` | Save mission configuration |
| POST | `/api/configure/remove` | Delete mission |

## Long-Term Tokens

Site Admins can create API tokens through the Configure page's Keys manager:
- Tokens can have expiration dates
- Used for automated access (CI/CD, scripts)
- Stored in the `long_term_tokens` database table

See `docs/pages/APIs/Configure/Configure_REST_API.md` for the full endpoint reference.
