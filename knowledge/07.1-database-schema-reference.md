# Database Schema Reference

Detailed column-level reference for all MMGIS database tables.

## configs

| Column | Type | Description |
|--------|------|-------------|
| `mission` | string | Mission name this configuration belongs to |
| `config` | JSON | Full configuration JSON object used by the MMGIS client |
| `version` | integer | Version number (increments on each save) |
| `createdAt` | timestamp | Row creation time |

## long_term_tokens

Stores API tokens for authentication via the Configuration API. Created by Site Admins through `/configure`. Can have expiration dates.

## webhooks

Stores a JSON list of active webhook configurations. Webhooks fire when their trigger action is performed.

## datasets

| Column | Type | Description |
|--------|------|-------------|
| `name` | string | Dataset name |
| `table` | string | Reference to data table (pattern: `d{int}_dataset`) |

Associated `d{int}_dataset` tables are tabular representations of CSV files.

## geodatasets

| Column | Type | Description |
|--------|------|-------------|
| `name` | string | Geodataset name |
| `table` | string | Reference to geo table (pattern: `g{int}_geodataset`) |

Associated `g{int}_geodataset` tables are tabular representations of GeoJSON with PostGIS `geom` column.

## user_files

| Column | Type | Description |
|--------|------|-------------|
| `file_owner` | string | Username of file owner |
| `file_owner_group` | string | Group owner (for Lead users) |
| `file_name` | string | Drawing file name |
| `file_description` | string | Description with encoded tags (`~^` elevated, `~@` folder, `~#` tag) |
| `is_master` | boolean | Is this a default Lead file |
| `intent` | string | File purpose (ROI, Campaign, etc.) |
| `public` | boolean | Visible to all users |
| `hidden` | boolean | Soft-deleted |
| `created_on` | timestamp | Creation time |
| `updated_on` | timestamp | Last update time |
| `template` | JSON | Metadata validation rules |
| `publicity_type` | string | How public: read-only, list-editors, all-editors |
| `public_editors` | string[] | Usernames who can edit (when publicity_type=list-editors) |

## file_histories

| Column | Type | Description |
|--------|------|-------------|
| `file_id` | integer | FK to `user_files.id` |
| `history_id` | integer | Incrementing per-file history ID |
| `time` | integer | Unix timestamp of the action |
| `action_index` | integer | 0=add, 1=edit, 2=delete, 3=undo, 5=clip(over), 6=merge, 7=clip(under), 8=split |
| `history` | integer[] | Array of `user_features` IDs in the file at this point |
| `author` | string | Username who performed the action |

## user_features

| Column | Type | Description |
|--------|------|-------------|
| `file_id` | integer | FK to `user_files.id` |
| `level` | integer | Rendering order |
| `intent` | string | Per-feature intent (overrides file intent) |
| `properties` | JSON | GeoJSON feature properties |
| `geom` | geometry | PostGIS-encoded geometry |

## published_stores

Intermediary spatial, relational, and hierarchical metadata for the publish validation workflow. Enables spatial search.

## publisheds

Published features from the last publish operation, with PostGIS-encoded geometries.

## session

Standard express-session table with connect-pg-simple. Enables session persistence across server restarts and horizontal scaling.

## spatial_ref_sys

PostGIS extension table. Catalog of spatial reference systems (EPSG, ESRI codes).

## users

| Column | Type | Description |
|--------|------|-------------|
| `username` | string | User login name |
| `email` | string | User email |
| `password` | string | Encrypted password |

Used when `AUTH=local` and for the Site Admin account.

## url_shorteners

Maps short character sequences to full deep links. Enables concise URL sharing.
