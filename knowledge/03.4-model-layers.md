# Model Layers

3D models rendered on the globe. Supports `.dae`, `.obj`, `.gltf`, and `.glb` formats.

## Properties

| Property | Type | Description |
|----------|------|-------------|
| Layer Name | string | Unique display name |
| URL | string | Path to 3D model file |
| Longitude | float | Placement longitude (decimal degrees) |
| Latitude | float | Placement latitude (decimal degrees) |
| Elevation | float | Placement elevation (meters) |
| Rotation X/Y/Z | float | Orientation (radians) |
| Scale | float | Scaling factor |
| Initial Visibility | bool | On by default |
| Initial Opacity | float | 0 to 1 |
| Time Enabled | bool | Enable temporal display |

## Alternative: Models via Vector Layers

Models can also be attached to vector features via `markerAttachments.model` in the vector layer's raw variables:

```json
{
  "markerAttachments": {
    "model": {
      "pathProp": "images.0.url",
      "mtlProp": "images.0.mtl",
      "pitchProp": -90,
      "pitchUnit": "deg",
      "show": "always"
    }
  }
}
```

This links feature points to 3D models that appear in both the Viewer and Globe panels.

See `docs/pages/Configure/Layers/Model/Model.md` for the full specification.
