# Other Layer Types

## Vector Tile Layers

Mapbox Vector Tiles for rendering large vector datasets efficiently. Tiles are streamed as protocol buffers and rendered client-side.

See `docs/pages/Configure/Layers/Vector_Tile/Vector_Tile.md` for details.

## Velocity Layers

Wind and velocity field visualization using the Veloserver adjacent service. Requires `WITH_VELOSERVER=true`.

See `docs/pages/Configure/Layers/Velocity/Velocity.md` for details.

## Video Layers

Video overlays on the map. Videos are georeferenced and play within the map viewport.

See `docs/pages/Configure/Layers/Video/Video.md` for details.

## Header Layers

Organizational headers that group layers in the layer list. Headers contain no data — they are purely for visual organization in the Layers tool.

See `docs/pages/Configure/Layers/Header/Header.md` for details.
